# Security policy

RISU Probe is an experimental offline-first diagnostic CLI. Its default `check` mode reads source without importing or executing that project. A saved transcript is not a live run, and static findings are not proof of runtime harm.

Do not include secrets, proprietary inputs, customer data, live credentials, private Git repositories or production MCP/HTTP captures in issues, PRs, build logs or artifacts.

**Report vulnerabilities privately.** Use GitHub's private vulnerability reporting feature if it is enabled in the repository's Security settings. Otherwise arrange a private channel with maintainers before disclosing sensitive details. Do not publish sensitive exploit traces as public issues.

This preview has no guaranteed security-support response time.
