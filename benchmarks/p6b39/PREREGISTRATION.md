## Primary analysis, including failure modes

- **FPR numerator** = organizations with an eligible, independently documented normal result and original executable consumer where the *unchanged B38 checker* raises an in-contract discrepancy that is actually contrary to a verified upstream normal policy. Unknown policy or missing observation => `INCOMPLETE`, **not false positive**, and ineligible. An intentional redaction/truncation flagged under a **deliberately incorrectly configured exact-preservation contract** is a separate **policy-mismatch challenge**, not a detector false alarm.
- Primary denominator reports `planned_normals=4`, `independently_executed_normals=n`, `in_scope_eligible_normals=m`, `false_alarms=k`, `normal_orgs_not_executed=4-n`, `ineligible=n-m`. Also report each organization's actual normal tests and severity; no silent replacement of a failed organization. Wilson 95% interval only if `m>0` (small purposive sample; do not generalize population).
- Per-case status `ORIGINAL_NATIVE_END_TO_END`, `ORIGINAL_SOURCE_FUNCTION_NATIVE_PEER`, `ORIGINAL_UPSTREAM_PARSER_OR_TEST`, `FIRST_PARTY_FIXTURE_ONLY`, `INCOMPLETE`, `NOT_EXECUTED`. The upstream's documented expected behavior and native wire must both be present for full channel verdict.
- Before/after fix controls from the *same* positive organization are matched controls, **not independent organizations for FPR**. Count and publish independently per channel and version.
- Independent holdout rule: after first B39 exposure the cases become development cases for any tuning. New semantic rules require a separate untouched B40 external cohort. A failed detector must not be tuned on B39 then relabeled prospective.
- Full Git SHA, original Git tree/blob, Git action run URL, raw native wire (sanitized synthetic payloads only), observed client result, explicit channel policy, verifier exact source Git blob and result SHA-256 must be retained. Expired or missing provenance is `UNVERIFIED`.

## Success versus non-success

Meaningful progress would be at least 2 unrelated independently authored **normal** consumer or producer implementations with *actual original runtime*, preserved status under explicit policy, and no unsupported channel claims. A genuine low observed false-alarm count is informative but not population FPR. At least one new unrelated **positive** original runtime with pre-fix discrepancy and fixed controls would extend B38 generalization. Negative outcomes and non-executed originals remain in the permanent report. The public product is unchanged until actual external user value and independent real normal FP burden are documented.
